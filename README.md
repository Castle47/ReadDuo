# ReadDuo

ReadDuo by Castle Zeng creates source-left / translation-right bilingual PDFs,
with resumable jobs, visual review and a separate issue checklist.

## Downloads

Desktop builds are published as release assets rather than committed to the
git tree. See the Releases page for the current macOS Apple silicon candidate.

## Release status

Build artifacts are local-evaluation candidates unless a release states
otherwise. Third-party components (including the PDF engine and its Python
runtime) retain their original terms; see the `third-party-licenses` folder
inside each archive. No new public license grant is made by these artifacts.

## Notes

Scanned pages need OCR before translation. Table interiors, pseudocode,
references and diagram labels remain source-owned by default; captions are
translated. Complex layouts may need review or retain disclosed findings.
